CMS Data Plugin adds import, export, and fixtures support to Softspring CMS content.

It provides admin import/export actions, structured data transformers, fixture loading, fixture dumping, and ZIP/YAML/JSON storage helpers for CMS content, routes, menus, blocks, and media references.
